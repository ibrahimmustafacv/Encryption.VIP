# 🔐 تشفير متقدم (Advanced Encryption)

تطبيق ويب بسيط وآمن لتشفير وفك تشفير النصوص والملفات باستخدام خوارزميات تشفير قوية، ويعمل بالكامل محليًا على جهاز المستخدم بدون إرسال أي بيانات إلى خوادم خارجية.

---

## 🚀 المميزات الرئيسية

- 🔐 تشفير وفك تشفير النصوص
- 📁 تشفير الملفات وتحميلها
- 🔑 دعم توليد مفاتيح تشفير
- 🌍 دعم أكثر من لغة
- 🖥️ يعمل مباشرة من المتصفح
- 🔒 تشفير محلي 100%

---

## 📝 طريقة الاستخدام

### 1️⃣ تشفير نص
1. افتح التبويب **🔐 الأساسي**
2. أدخل النص في حقل **"النص المدخل"**
3. اختر خوارزمية التشفير (مثل **AES-256**)
4. أدخل مفتاح التشفير أو استخدم زر **"توليد مفتاح"**
5. اضغط على زر **🔒 تشفير**

---

### 2️⃣ فك تشفير نص
1. أدخل النص المشفر في حقل الإدخال
2. تأكد من اختيار نفس الخوارزمية المستخدمة في التشفير
3. أدخل نفس مفتاح التشفير
4. اضغط على زر **🔓 فك التشفير**

---

### 3️⃣ تشفير الملفات
1. انتقل إلى تبويب **📁 الملفات**
2. اختر الملف المراد تشفيره
3. اضغط على زر **"تشفير الملف"**
4. استخدم زر **"تحميل الملف"** لحفظ الملف المشفر
